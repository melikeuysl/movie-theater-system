🎬 CineMate
Movie Theater Ticket Management System

CineMate is a full-stack web application developed as a team project for a Software Engineering course.
It simulates a real-world online movie ticket booking platform where users can browse movies, select seats, complete secure payments, and manage their bookings.

The project follows an Agile development lifecycle with sprint planning, user stories, and incremental delivery.

🎯 Project Objectives

- Build a scalable and realistic ticket booking platform

- Apply Agile software development practices

- Implement secure authentication and payment workflows

- Practice full-stack system design and collaboration

🚀 Key Features

🎟️ Customer Features

- Browse movie catalog with detailed information

- View showtimes by theater and date

- Interactive seat selection with availability validation

- Secure online payment and booking confirmation

- Booking history and favorites management

- User authentication and account management

- Upcoming releases browsing

🛠️ Admin Features

- Dashboard for bookings, revenue, and users

- Movie and show management (CRUD)

- Booking monitoring and reporting

- Role-based user management

🧩 System Architecture

User Service – Authentication and role management

Movie Service – Movie catalog and metadata

Show Service – Scheduling and seat availability

Booking Service – Reservation lifecycle

Payment Integration – Secure transactions

🔁 Development Process

Sprint 1–2 → UI, navigation, movie listing and details

Sprint 3 → Seat selection, payment, booking confirmation

Sprint 4 → Authentication, favorites, admin dashboard

Sprint 5 → Unit testing and project demonstration

⚙️ Installation

- git clone https://github.com/melikeuysl/movie-theater-system.git
- cd movie-theater-system
- npm install
- npm run dev

⚠️ Environment variables must be configured for authentication and payment services.
